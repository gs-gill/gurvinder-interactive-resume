# Gurvinder Singh Gill — Interactive Résumé

Open `index.html` in a modern browser. The experience is self-contained and uses original CSS-built artwork; no build tools or external libraries are required.

## Controls
- Mouse wheel or trackpad scroll advances horizontally through sections.
- Left/right and up/down arrow keys, Page Up/Down, Space, Home, and End navigate the scenes.
- On touch screens, swipe left/right to move between scenes.
- Use the top navigation, side dots, and lower-right arrows for direct navigation.

The supplied `resume_2023.pdf` is included as a printable/downloadable résumé.
