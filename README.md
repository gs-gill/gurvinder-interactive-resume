# Gurvinder Gill — Portfolio

A personal portfolio for Gurvinder Gill. The home page leads with his cloud and data technology range, then presents verified work, education, and contact details. The optional driving page remains available from the footer. The main page follows an editorial Engineering Journal design.

## Pages

- `index.html` — main portfolio, with direct section navigation and resume download.
- `style.css` and `site.js` — responsive presentation and active section navigation.
- `assets/` — self-hosted fonts, technology icons, and the paper texture used by the main portfolio.
- `park.html` — optional illustrated driving portfolio. Use the **← Portfolio** button to return.
- `gurvinder-resume-2026-1.pdf` — latest printable resume.

Open `index.html` in a browser or serve this folder with any static web server. The site is ready for GitHub Pages. It needs no build step, framework, or external network assets.

## Park controls

- Drive with **W/A/S/D**, arrow keys, or the on-screen touch controls.
- Press **E** or select **Explore nearby** at a marker.
- Use **Map** or press **M** to jump to a stop; **Menu** lists all sections.
- Toggle the quiet engine tone with the sound button.
